# 01 - Quick Start

This page helps you make your first NovaAPI request in three minutes.

## What is NovaAPI?

NovaAPI is an AI capability access and application service platform. It lets developers call models through a unified API and provides authentication, usage metering, billing, vertical APIs, and agent services.

With NovaAPI, you can:

- Call multiple models through one unified API
- Manage API keys, balances, bills, and usage
- Connect models to applications, scripts, agent tools, or workflow platforms
- Use vertical APIs and agent services (coming soon)

## The three essentials

An API request normally requires a Base URL, an API key, and a Model ID.

## Your first API request

> The following example uses the OpenAI-compatible API.

```bash
curl https://api.novaapis.com/v1/chat/completions \
  -H "Authorization: Bearer $NOVAAPI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "YOUR_MODEL_ID",
    "messages": [
      {"role": "user", "content": "Hello, please introduce yourself."}
    ]
  }'
```

On success, the response contains the model output.
