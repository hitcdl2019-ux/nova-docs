# 02 - Registration and Sign-in

This page explains how to create a NovaAPI account, sign in to the console, and complete the basic setup.

## Registration

1. Open the [NovaAPI website](https://api.novaapis.com/).
2. Select **Sign in** in the upper-right corner.
3. Register with a username or email address, or authenticate with GitHub or Google.
4. Review the Terms of Service and Privacy Policy, then follow the prompts to create your account.

## After your first sign-in

We recommend completing these steps in order:

1. Complete your account information under **Profile**.
2. Create your first API key on the API key management page.
3. Open the model marketplace and choose a Model ID.
4. Make your first API request.

## Account security

### Sign out

Select your profile picture in the upper-right corner, then select **Sign out**. Always sign out after using a shared or public device.

### If an API key is exposed

1. Immediately delete or disable the exposed key on the API key management page.
2. Review recent usage, bills, and request logs. If you find unexpected charges, contact [contact@novaapis.com](mailto:contact@novaapis.com).
