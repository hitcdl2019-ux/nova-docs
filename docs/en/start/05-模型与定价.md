# 05 - Models and Pricing

This page explains how to browse supported models, choose a Model ID, and understand pricing.

## Model center

The model center displays:

- Model name and Model ID
- Provider
- Context length
- Supported protocols
- Streaming support
- Tool-calling support
- Structured-output support
- Image input and multimodal support
- Pricing

## Finding a Model ID

The Model ID is the value passed in the request's `model` field:

```json
{
  "model": "YOUR_MODEL_ID",
  "messages": [{"role": "user", "content": "Hello"}]
}
```

Use the copy button beside a model in the model center. A model's display name and Model ID may differ, so always use the Model ID in API requests.

## Billing

Charges follow the corresponding model provider's official pricing rules.

## Model pricing

Pricing, context limits, capabilities, and availability may change with upstream providers. Refer to the model center for current information.

For enterprise usage requirements, contact [contact@novaapis.com](mailto:contact@novaapis.com).

## If a model is unavailable

Check that:

1. The Model ID is correct.
2. The API key has permission to use the model.
3. The account has sufficient balance.

If the issue persists, contact [contact@novaapis.com](mailto:contact@novaapis.com).
