# 02\-注册与登录

本页介绍如何注册 NovaAPI 账号、登录控制台，并完成首次使用前的基础设置。

## 如何注册

1. 打开 NovaAPI 官网：[https://api\.novaapis\.com/](https://api.novaapis.com/)

2. 点击右上角“登录”按钮

3. 选择注册方式：可通过用户名或电子邮件进行注册，也可通过 GitHub 或 Google 账号验证登录。

4. 按页面提示查看《用户协议》和《隐私政策》，确认无误后完成账户创建。

## 首次登录后要做什么

建议按以下顺序完成：

1. 进入“个人资料”完善账户信息；

2. 进入 API 密钥 管理页，创建第一个 API Key；

3. 查看模型广场并选择 Model ID；

4. 完成第一次 API 调用。

## 账号安全

### 登出账号

登出入口：点击页面右上角个人头像，点击“登出”即可。

如果你在公共设备上登录，使用完毕后请及时登出。

### API Key 泄露怎么办

如果怀疑 API Key 泄露，请立即：

1. 进入 API Key 管理页，立刻删除或禁用泄露的 API Key；

2. 检查近期用量、账单和请求日志，如发现异常消费，请发送邮件至contact@novaapis\.com 获取支持。
