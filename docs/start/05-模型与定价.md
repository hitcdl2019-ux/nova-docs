# 05\-模型与定价

本页介绍如何查看 NovaAPI 支持的模型、选择 Model ID，并理解计费方式。

## 模型中心

可以在模型中心查看：

- 模型名称

- Model ID

- 模型供应商

- 上下文长度

- 支持协议

- 是否支持流式输出

- 是否支持工具调用

- 是否支持结构化输出

- 是否支持图片输入 / 多模态

- 价格

## 如何查看 Model ID

Model ID 是 API 请求中 `model` 字段的值。

示例：

```JSON
{"model": "","messages": [{"role": "user", "content": "你好"}]}
```

在模型中心页面，每个模型名称后有“复制”按钮，点击复制进行使用。

注意：模型展示名称和 Model ID 可能不同，调用时请使用 Model ID。

## 计费说明

与模型官方定价规则保持一致。

## 模型价格

模型价格、上下文、能力和可用性可能随上游变化而调整，请以模型中心页面展示为准。

若有企业级用量需求，请联系商务洽谈：contact@novaapis\.com

## 模型不可用时怎么办

请检查：

1. Model ID 是否填写正确

2. API Key 是否有该模型权限

3. 余额是否充足

如仍无法调用，请联系支持：contact@novaapis\.com
