# 03\-充值余额与发票

本页介绍 NovaAPI 的充值入口、余额查看、扣费规则、账单记录和发票申请方式。

## 充值入口

操作路径：

1. 登录控制台，进入充值页面；

2. 选择充值金额，提交充值申请；

3. 扫描二维码添加客服，并发送充值单号；

4. 根据客服提示完成充值，保留付款凭证并上传；

5. 客服在后台审核通过后完成充值。

## 余额查看

在充值页面，将显示您的可用余额，请您关注可用余额情况，在余额不足时及时充值，以免影响您的正常使用。

## 扣费规则

与模型官方扣费规则保持一致。

## 账单与消费明细

您可以在数据看板页面查看模型调用整体情况，在使用日志页面查看每一笔调用的具体消耗。

## 发票申请

线下充值入账后可申请发票。

选择已入账的充值记录，并提交发票信息。

单次开票金额不低于100元，已开具发票的金额不予退款。

客服人工审核后将为您开具发票。开票周期为 7 个工作日左右，电子发票将发送到您制定的邮箱。

开票信息一经提交，无法修改，如有问题，请联系我们：contact@novaapis\.com。
