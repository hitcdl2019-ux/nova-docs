# 01\-快速入门

本页帮助你在 3 分钟内完成 NovaAPI 的第一次 API 调用。

## NovaAPI 是什么

NovaAPI 是一个 AI 能力接入与应用服务平台，帮助开发者通过统一接口调用模型能力，并提供鉴权、计量计费、垂类 API 与 Agent 服务，降低 AI 能力在业务系统和工具中的接入与管理成本。

你可以通过 NovaAPI：

- 使用统一 API 调用多个模型

- 管理 API Key、余额、账单和用量

- 将模型能力接入应用、脚本、Agent 工具或工作流平台

- 使用垂类场景的API与Agent服务（敬请期待）

## 第一次 API 调用

> 以下示例使用 OpenAI 兼容接口。
> 
> 

```Bash
curl /chat/completions \-H "Authorization: Bearer " \-H "Content-Type: application/json" \-d '{
    "model": "",
    "messages": [
      {"role": "user", "content": "你好，介绍一下你自己"}
    ]
  }'
```

成功时，你会收到模型返回的文本内容。
